install-linux.sh

The whole Linux CLI installer, fetched live from the same URL the command below reads. Nothing here is a copy — this is the file that runs. 

curl -fsSL https://saadhu-xyz.github.io/install-linux.sh | bash

It is short on purpose. It reads the release manifest, downloads the tarball for this machine, checks it against the published SHA256, unpacks it, and runs the install-anton.sh that ships inside the release. The install steps themselves live in the tarball, versioned with the build they install — so what you read below is the fetch-and-verify half, and the release carries the other.

Nothing here needs root: the binaries land in ~/.local/share/anton, the commands in ~/.local/bin, and the services run as systemd user units.
